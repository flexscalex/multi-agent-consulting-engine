# v1 (kept for reference)

The original engine: three consulting-firm personas compete on a brief across two rounds, a review panel ranks them, and a partner synthesizes. It is preserved here unchanged. The `main` branch still carries it at the repo root.

Why v2 replaced it: the pitch framing rewarded ambition over accuracy, every proposal had to include a pilot (no way to say "do not proceed"), sources were free-text strings that nothing verified, and round 2 answered follow-ups it had not researched. See the root README for what changed.
